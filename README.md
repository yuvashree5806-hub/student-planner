# 📚 Student Planner

A full-stack Student Planner web application designed to help students organize their academic activities efficiently. The application provides tools for timetable management, task scheduling, reminders, timers, and productivity tracking in one place.

## 🚀 Features

### ⏰ Timetable Management
- Create and manage class schedules.
- View daily and weekly timetables.
- Organize subjects by day and time.

### ✅ Task Management
- Add, edit, and delete academic tasks.
- Track assignment deadlines.
- Mark tasks as completed.

### 🔔 Reminder System
- Set reminders for important tasks and events.
- Receive notifications for upcoming deadlines.

### 📖 Subject Management
- Add and manage subjects.
- Organize tasks and schedules by subject.

### ⏱️ Stopwatch
- Start, pause, and reset stopwatch.
- Useful for study sessions and productivity tracking.

### ⌛ Timer
- Set countdown timers for focused study periods.
- Helps implement techniques such as Pomodoro.

### 📅 Calendar View
- Visualize schedules and events.
- Track important academic dates.

### 👤 User Authentication
- User registration and login.
- Secure authentication system.

## ⚙️ Installation

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/student-planner.git
```

### 2. Navigate to Backend
```bash
cd student-planner/backend
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Environment Variables
Create a `.env` file inside the backend folder:
```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

### 5. Start the Backend Server
```bash
npm start
```

### 6. Open Frontend
Open `index.html` in your browser or use Live Server in VS Code.
